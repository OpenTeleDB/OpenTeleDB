# Open**TeleDB**数据库**开源**社区**行为准则**

本文主要介绍OpenTeleDB数据库开源社区行为准则，通过该准则确保我们拥有一个尊重、包容的交流环境。

欢迎来到OpenTeleDB数据库开源社区！

我们很高兴您加入OpenTeleDB数据库开源社区，该社区是由广大的开发者、用户、合作伙伴一起建立的分享、学习OpenTeleDB数据库的平台。在这里，我们可以互相协助解决问题、分享技术经验。为了更好的维护网络环境与健康的运营，我们制定了一系列的行为规则，具体如下：



**基本原则**

1. 我们鼓励互助、互动，但请保持友善交流，不可进行人身攻击，尊重社区的任何一个成员，讨论问题时请尽量做到有理有据，请尽量提供合理的回复来说服别人，切勿令冲突升级。

2. 请规范使用用户名、头像、个人资料和签名，不得冒充OpenTeleDB数据库开源社区官方人员身份，不得使用容易引起混淆的名称、头像和内容发布信息。

3. 请遵守法律法规，避免宗教、政治或其他不恰当的言论，禁止钓鱼、滥发消息、骚扰或造谣等行为。

4. 请勿灌水、发广告、刷屏等 OpenTeleDB数据库开源社区成员都不喜欢的行为。

5. 参与OpenTeleDB数据库开源社区互动其实也是一个社交活动，需要个人把握社交分寸，遵守基本的社交礼仪，不可接受的参与者行为包括但不限于：

   - 讨论问题上升到人身攻击，挑衅、侮辱或贬低性评论；

   - 公开或私下骚扰；
   - 未经允许发布他人私人信息；
   - 未经允许发布广告或者其它不良信息；
   - 无故刷屏刷帖从而占用公共资源等。
